↓ the three-stage contract the clients drive
📝 Stage 1 — Storyboard generation
🤖

call_llm_with_fallback

Provider chain gemini → openrouter → groq; schema-forced output (response_schema=StoryboardResponse), json_repair-lenient parse

→
🗄️

Storyboard cache

.storyboard_cache/ — content-hash key = ∞ TTL, topic key = 48h TTL. Cache-key changes are billing changes

→
📐

StoryboardResponse

topic, key_theorems/terms, style_profile, aspect_ratio, visual_storyboard[]: scenes with elements + narration_cues + layout_template + composition (scene-level layout gestalt descriptor)

🏗️ Stage 2 — Codegen (Visual Director + transpiler + critic) diagrams 04
🎬

Visual Director flag-gated

pipeline/director.py (VISUAL_DIRECTOR=1): LLM ranks element importance → code applies scale tiers, safety-gated hide events, capped highlights. LLM never emits geometry. Stands aside on failure. 24-check harness.

→
⚡

transpiler.py

parse_schema_to_base_scene (one master script) + parse_schema_to_scene_scripts (one per scene, for parallel render). No LLM in this stage

→
🧼

sanitize + Layout QA Critic

Strips hallucinated imports, normalizes viz_helpers star import, enforces language policy + config.font. Then Layout QA Critic (LLM pass) reviews the generated code.

→
📦

Output

Manim code + scene_class + scene_scripts[] back to the caller for compile

🎞️ Stage 3 — Render job (_run_render_job)
🚦

Path choice

scene_scripts > 1 and PARALLEL_RENDER≠0 → parallel fast-path; else sequential single-script

→
🧵

_render_scenes_parallel

ThreadPool (PARALLEL_RENDER_WORKERS=4) renders every scene script concurrently

→
🛡️

_repair_scenes_parallel

Scene-scoped overlap repair — only flagged scenes re-render (diagram 03)

→
🔗

_concat_scene_clips

ffmpeg concat → one mp4 + .mp4.json sidecar via _write_video_sidecar

Sequential fallback: compile_manim_code → self-heal loop on compile errors (repair_code_with_gemini, max 2 rounds) → _repair_overlaps whole-video repair. Same accept-if-better contract; every loser deleted via _discard_video.
👁️ Stage 4 — Vision QA (frame audit) flag-gated
🎞️

_run_vision_qa

VISION_QA=1: ffmpeg extracts VISION_QA_FRAMES (6) evenly-spaced 640px frames from the rendered mp4

→
🤖

Multimodal LLM

app.llm.call_vision_llm (gemini-2.5-flash chain) against a 7-class whitelist: clipped/colliding/unreadable text, crowding, dead-frame, low-contrast, broken-hierarchy

→
📐

Whitelist gate

Findings lenient-parsed, shape+whitelist gated; timestamps snapped to frames. Emitted as LAYOUT_VIOLATION: vision-<class> — never counted by geometric _overlap_violations

→
⚖️

Repair (sequential only)

Sequential path: full accept-if-better vision-repair round (geometric non-regression guard). Parallel path: measurement-only — findings in vision_findings sidecar field. 19-check harness.

🤖 LLM fallback chains

Gemini native (google.genai, GEMINI_API_KEY): gemini-2.5-flash → 2.5-pro → 2.0-flash

OpenRouter: storyboard gemini-2.5-flash → deepseek-v4-pro → llama-3.3-70b:free · code deepseek-v4-pro · vision QA gemini-2.5-flash

Groq last resort: llama-3.3-70b-versatile

Chains overridable: GEMINI_MODELS, OPENROUTER_STORYBOARD_MODELS, OPENROUTER_CODE_MODELS, VISION_QA_MODELS

🗣️ TTS — narration with shared cache

UniversalTTSService (viz_helpers) wired into every generated scene; provider default sarvam, Gemini TTS fallback (no SARVAM key on this box)

Cross-render cache .tts_cache/: key = sha256(text+lang+speaker+provider); audio written first, json last (atomic)

Contract: a repair re-render bills ZERO TTS calls; cache failures are non-fatal

TTS_SHARED_CACHETTS_SHARED_CACHE_DISABLE
📦 Bulk pipeline — bulk_runner.py

Stages per topic: storyboard → codegen → render, each cached in bulk_runs/<run_id>/<topic>/ — a dead run resumes with zero re-billed LLM calls

CLI: python3 bulk_runner.py plan.json [--parallel N] [--resume ID] [--dry-run]

Web: /bulk UI with per-topic stage status + retry
