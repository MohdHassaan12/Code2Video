🐧 Environment gotchas (Linux dev box)

No committed venv on Linux — .venv expectation is Windows (run_app.ps1); create with python3 -m venv .venv. python is not on PATH

Keys in stem_animation_lab/.env; no SARVAM key → TTS falls back to Gemini TTS via OpenRouter. ce/agents.py reads OPENROUTER_API_KEY at import time — load .env first

Missing json_repair degrades to plain json.loads — symptom is a storyboard 500 on trailing commas, not an ImportError

Restart uvicorn after editing app.py — a running server keeps old code

.gitignore doesn't retroactively untrack — after merging origin, check git ls-files -i -c --exclude-standard and git rm --cached on purpose

🧪 Test harnesses real renders · LLM stubbed · no keys

test_overlap_probe.py — 32 checks: probe detection, whole-video repair state machine, scene-scoped parallel repair. Asserts the no-leak contract: a rejected round leaves ZERO net new mp4s

test_layout_safety.py — deterministic viz_helpers layer (--unit for the fast part)

test_axes_zones.py — 14 checks: zone-placed text routes around the axes' real bbox; labels flip away from tick strips; bottom-zone stacking shifts INTO the frame

test_tts_shared_cache.py — 10 checks: a repair re-render bills ZERO TTS calls; different text/voice synthesizes fresh; cache failures are non-fatal

test_event_sanitize.py — 20 checks: model-authored prose never reaches self.play(...); bare element ids are dropped; valid calls and .animate chains survive

test_minimize_split.py — 20 checks: text pile-up on a diagram splits the screen; lone captions / anchored labels / cue 0 do NOT; selective viz_helpers import widens to star import

test_entrance_map.py — 14 checks: mixed-type scene emits ≥4 distinct entrance classes; shape keywords map with the same precedence as _build_obj_expr; schema overrides win

test_storyboard_gate.py — 26 checks: pre-cache storyboard shape/language gate + on-screen-language healing; hybrid contract enforcement (Devanagari rejection, all-English rejection); heal accepted only if it removed Indic script

test_director.py — 24 checks: Visual Director IR application (scale tiers, safety-gated hides, capped highlights, strip-invariance); LLM stubbed, input board never mutated

test_vision_qa.py — 19 checks: Vision QA with real ffmpeg on synthetic clip; whitelist/shape-gated findings; accept-if-better round with geometric non-regression guard; losers discarded

test_ir_contracts.py — 17 checks: drift gate (schema JSON = Pydantic export), golden-storyboard round-trip, degenerate-board rejection, sidecar schema contract

Plus: test_generate_code.py (integration — needs the lab running) · test_smart_plane.py (manim scene exercising viz_helpers' SmartCoordinatePlane/SceneManager)

House pattern: every harness stubs the LLM and needs no API keys, so failures are deterministic and free to reproduce. New real-world failure ⇒ new pinned check, in the same pass as the fix.
