Layout Enforcement v5 — Overlap Probe & Repair Loop

Every render is dry-run probed for text overlaps, edge clipping, and text-over-shape collisions + optional multimodal Vision QA frame audit; an LLM repair agent fixes flagged scenes — but a fix is only accepted if it renders AND reduces violations. The original video is never lost.
Diagram 03 — Layout enforcement · lives in stem_animation_lab/app/render.py · full design: docs/layout_framework.md · Vision QA in app/pipeline/vision_qa.py
🔍 1 · Detection — two independent probes
💉

Geometric probe (always on)

_OVERLAP_PROBE_SNIPPET injected into the scene script; patches Scene.play to measure after every beat. Three classes: text-on-text overlap · text clipped at frame edge · text-over-shape (stroke path crossing a text bbox).

👁️

Vision QA flag-gated

VISION_QA=1: ffmpeg extracts 6 evenly-spaced 640px frames → one multimodal LLM call. Seven classes: clipped / colliding / unreadable text, crowding, dead-frame, low-contrast, broken-hierarchy. Findings as LAYOUT_VIOLATION: vision-<class> — never counted by the geometric probe.

🧾

Parseable output

Both probes emit LAYOUT_VIOLATION: lines on the render log — the machine-readable contract

→
📋

Error brief

_overlap_error_report condenses geometric lines; vision findings go to vision_findings in the sidecar

Probe traps (hard-won): MathTex.get_fill_opacity() is 0.0 at top level — use family-aware _ovl_visible · containers like NumberLine/Arrow carry their own points AND submobjects — check both · NumberPlane/ComplexPlane are backdrops, never violations.
↓ LAYOUT_VIOLATION lines found → enter repair
🔧 2 · Repair — three paths, one contract
⚡

_repair_scenes_parallel default

Multi-scene path — repairs per scene, so only flagged scenes re-render. Cheapest wall-clock; used by the parallel render pipeline.

🎞️

_repair_overlaps

Whole-video loop — used by the sequential fallback and the batch path. Same accept/reject contract, coarser re-render unit.

👁️

_run_vision_qa flag-gated

Vision QA repair round (VISION_QA_REPAIR=1). Sequential only in v1: accept-if-better with geometric non-regression guard. Parallel path: measurement-only.

🖥️ Screen management — split-screen

_maybe_minimize_diagram: when a cue piles free-standing text onto an on-screen diagram → diagram shrinks to left half, text stacks in a right column

Trigger: any math, or ≥2 text-ish elements

Never on: cue 0 (diagram still arriving) · diagram-anchored labels (they ride the shrink)

⚠️ Per-scene isolation trap

Each per-scene script starts from a blank canvas with only its OWN id→var map; emitters fall back to the raw storyboard id on a miss

A cross-scene event used to emit FadeOut(container) → NameError (killed 3 of 4 scenes, 2026-07-20 Dalton run)

Fix: _drop_cross_scene_events / _drop_foreign_id_calls — per-scene path ONLY; the master single-script path legitimately shares one namespace
