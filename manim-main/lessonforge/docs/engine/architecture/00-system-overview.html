🤖 LLM / Model Providers

Gemini native (google.genai) — lab primary for storyboard & codegen (GEMINI_API_KEY)

OpenRouter — lab fallback chain + ALL ce/ agents + Gemini-TTS fallback (OPENROUTER_API_KEY)

Groq — last-resort fallback (GROQ_API_KEY)

Metered edges: every LLM call routed by task tier — premium models only where output quality depends on it; cache-key changes are billing changes. Keys in stem_animation_lab/.env.
🛡️ Quality Invariants

Never lose a verified artifact — the original video survives every repair attempt

Accept only improvement — a fix must render AND reduce violation count

Every loser is deleted — rejected candidates & superseded originals never pile up

Deterministic structure — no per-block LLM decoration of generated code

Progress or it's a hang — long runs log per-beat / per-scene lines
