🧠

ce/ — Lesson & Video Pipeline (client side)

The lesson-side pipeline that decides which nodes deserve a video, plans the pedagogy, and drives the stem_animation_lab server over HTTP — then merges the returned clips into the final lesson video.
Diagram 01 — ce/ video flow · server side is diagram 02
🎬 Video build chain (per lesson)
🗂️

videos_build.py

generate_lesson_video / generate_single_video — loops lesson nodes; tags video.provider = "stem_animation_lab"

→
🤔

video_planner.py

analyze_node() — LLM decides IF a node needs a video + its type: MISCONCEPTION · PROCESS · EXPERIMENT · VISUALIZATION

→
🎛️

video_generation.py

generate_animation() — plan clips → generate each → merge. Returns {path, clips}

→
✂️

clip_planner.py

plan() — currently hardcoded to exactly 1 clip per node

📡

stem_animation.py — the HTTP client

Per clip: pedagogical plan (planner_agent) + grounding (storyboard_context) → POST /api/generate_storyboard → /api/generate_code → /api/compile_video → status via WebSocket /ws/render_status/{job_id} (HTTP poll fallback) → download mp4 to generated_videos/

→
🧵

video_merger.py

merge_videos() — ffmpeg concat of clips + optional bgm.mp3 mix (volume 0.08, amix) → final video in generated_videos/

↓ feeds topic + pedagogy + persona to the server (diagram 02)
📚 Pedagogy & grounding (before the server sees anything)
🧑‍🏫

planner_agent.py — pedagogical storyboard

PARTS / Google LearnLM framework. generate_pedagogical_plan(topic, grade, ncert_content, …) · determine_scene_count(): 4–10 scenes · narration_wpm(): 90 wpm for grade ≤ 4, else 150 · emits scenes[{scene_number, core_idea, visual_description, voiceover_script}]

🌏

storyboard_context.py — grounding

resolve_context() resolution order: YouTube transcript → content_store (NCERT) → none. Keeps storyboards anchored to real curriculum content instead of model free-association

🔌 Model seam — every ce/ LLM call goes through agents.py
🧩

agents.py

complete_json / complete_text / complete_vision. Provider: OpenRouter preferred, else Anthropic. Default model CE_MODEL env or claude-sonnet-4.5. No key → returns None → deterministic fallbacks

🎚️

modelcfg.py

Per-task model routing, persisted in content_store/model_config.json — live config: google/gemini-2.5-flash for all tasks; LearnLM tier google/gemini-2.5-pro

💰

usage.py

Token/cost accounting — usage.record / total / reset. Metered edges: every call is attributable

Import-time trap: ce/agents.py reads OPENROUTER_API_KEY at import time — load stem_animation_lab/.env before importing anything under ce/.
