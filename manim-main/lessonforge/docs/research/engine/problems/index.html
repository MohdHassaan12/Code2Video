0What this system does, in plain words

🎬 Type a topic, get a narrated teaching video no jargon

You give it a school topic — say, “distance between two points.” A few minutes later you get a short, narrated animated video that teaches it, in Hinglish by default. Nobody draws anything, records anything, or edits anything by hand. It works in six steps:

🧭

1 · Decide

A planner reads the lesson and decides whether this topic needs a video, how long, and what kind.

→
✍️

2 · Write the script

An AI writes a scene-by-scene script: what appears on screen, and what the narrator says.

→
🚧

3 · Check the script

Automatic gates reject scripts that are cut off, malformed, or in the wrong language — before any money is spent drawing them.

→
📐

4 · Draw by rules

A rule-based translator turns the script into drawings. Positions, sizes and timing are computed by code, never guessed by AI.

→
🎙️

5 · Add the voice

A text-to-speech service reads the narration. If one voice provider is down, it falls back to the next, ending at one that needs no account at all.

→
🔍

6 · Watch & repair

Before publishing, the system measures its own video for overlapping or cut-off text, repairs what it finds, and keeps whichever version is better. Every video ships with a report card.

Two parts do this work: a lesson pipeline (ce/) that walks the lesson and asks for videos, and a video lab server (stem_animation_lab/) that writes, draws, narrates, checks and repairs them. They talk over HTTP. Full picture: the system-overview diagram.

1The thesis these problems sit under

This repo’s bet: an AI educational video system is a compiler — “models own content, code owns structure, probes own truth  — at every layer, enforced by gates” reference-architecture.md:87. Every research-grade problem below lives where one of those three ownerships runs out of road.
🔍

V · Probes own truth — but only geometric truth

The probe measures overlap and clipping, not whether a frame communicates. Truth beyond geometry is unowned.

📐

S · Code owns structure — but structure isn’t meaning

The deterministic layout engine prevents collisions; it cannot yet realize intent — composition, emphasis, timing against speech.

🔁

L · The loop doesn’t close

The system doesn’t learn from its own history (repair memory inert) and can’t account for itself (no cost ledger, no durable state).

📚

C · Models own content — and content is ungated

Gates check shape and language, not truthfulness to the source or teaching quality. Weak pedagogy compiles flawlessly.

What this page is not. Not a bug list — the build is healthy (12/12 harnesses, 253/253 checks green, measured 2026-07-27, including the real-render overlap probe), and bugs here get fixed in days (the six-run Dalton catalogue, pipeline-roadmap.md:704-712, proves it). Not a wishlist either — features with a known build plan belong on the roadmap. A problem appears below only if the flaw has no known reliable fix in this repo’s accepted shape: deterministic + gated + measured.

4The problems — ordered by how much each compounds the others

PROBLEM 01

No end-to-end quality score

V · verificationT2→T3L0–L1

The probe scores geometry; nobody scores whether the video teaches. Every non-geometric lever — prompts, Director, pacing, entrances — is tuned by eyeball. The measurement gap ranks first because it gates all the rest.

Evidence: “no narration QA at all; no fidelity-to-source QA” pipeline-roadmap.md:510-511; stage G graded L2.5 for geometry only.
PROBLEM 02

Durable state, cost & run ledger

L · loopT1L1

The one honest T1 on this page — kept because it compounds: without per-run folders and a cost ledger, no experiment on problems 01–10 can be compared or afforded rationally. LLM calls have no timeout, so a hung call leaves a job “running” forever.

Evidence: stage H = L1, “biggest operational gap … no cost tracking at all” pipeline-roadmap.md:581,594-596; no-timeout gap pipeline-roadmap.md:494-501.
PROBLEM 03

Trustworthy machine perception

V · verificationT3◐ L1

Vision QA is built and wired — and default-off, because its perception can’t yet be trusted: findings must be whitelist-gated, and one live round spent 4 rewrites + 4 re-renders and “bought nothing.”

Evidence: 6/6 “dead frames” were a sampler artifact (frames landed on scene starts) pipeline-roadmap.md:352-363; cost note pipeline-roadmap.md:566-568.
PROBLEM 04

Repair-loop convergence

S · structureT2L2

Accept-if-better repair is greedy descent with an LLM proposal distribution — no theory of when it stalls. And it is the one place an LLM edits geometry, against the house thesis that code owns structure.

Evidence (measured on disk): 7/17 sidecars ship with residual violations — one still at 6 after 3 rounds, one at 3 after 4 rounds.
PROBLEM 05

Composition intent never reaches the solver

S · structureT1L1

The LLM writes a layout gestalt for every scene ("title banner top, derivation stacked right"); the transpiler consumes it as a log line. Layout is collision-free but semantically blind. 2026-08-03: fix strategy specified — closed keyword vocabulary (7 patterns) mapped to layout_template zones, ~60 lines of deterministic code, $0, no schema change.

Evidence: composition populated at app/storyboard.py:420, read only by transpiler.py:822-823 logging. Containment + place_inside() shipped 2026-08-01.
PROBLEM 06

Narration–animation sync by construction

S · structureT2L1

Entrances play against whole-cue audio; after the entrance, the rest of each beat is dead air. There is no shared timeline IR where narration words and animation events meet.

Evidence: “sync is approximate … dead air” pipeline-roadmap.md:172-174; open roadmap item #11, per-element narration beats.
PROBLEM 07

Self-improving repair memory is inert

L · loopT2○ L1

The error→fix store is fully coded on both sides — and disabled: CHROMADB_ENABLED defaults off, and the read side was dropped in a merge except for LaTeX. The system re-derives every fix from scratch.

Evidence: app/rag.py:17 early-return; read-side gap reference-architecture.md:903-908; 185 unmined debug traces on disk (measured).
PROBLEM 08

Grounding without a fidelity gate

C · contentT2L1

Source text goes into the storyboard prompt — and nothing checks what comes out against it. An invented number is indistinguishable from a sourced one, in a system whose whole point is teaching facts.

Evidence: “nothing prevents the storyboard from inventing numbers/examples not in the source” pipeline-roadmap.md:63-64; planned ≥95% fidelity bar not built pipeline-roadmap.md:66-69.
PROBLEM 09

Pedagogy compiles unverified

C · contentT3L0

Admission gates check shape, truncation and language — never teaching quality. The repo says it itself: “a pedagogically weak learning plan compiles into a pedagogically weak video, flawlessly.”

Evidence: chapter-4-architecture.md:371-382; the 23.7s Dalton video that “never states the law” pipeline-roadmap.md:708.
PROBLEM 10

The verifier sets the expressiveness ceiling

V · verificationT2L0 by design

Camera zoom/pan are deliberately absent — a moving camera would blind the fixed-frame probe. General form: every new visual capability must ship with its verifier, and nobody knows how to make probes capability-independent.

Evidence: “Implement camera moves only together with a frame-aware probe” CLAUDE.md:166-173; open roadmap item #17.
PROBLEM 11

The scene has no structure to lay out

S · structureT2L1 (edges + containment shipped)

The IR is a flat bag of positioned elements — an element cannot say what it contains or connects to. So models smuggle structure into prose ("branches from 84 to circles containing 12 and 7") and the child nodes never exist. 2026-08-03: fix roadmap specified with 6 concrete, independently shippable strategies — composition descriptor → layout (#1, $0), wire shape_overlaps into repair (#2), mid-transition sampling (#3), mass/balance solver (#4), row/column IR primitives (#5), constraint solver (#6). Shape×shape overlap is now measured (shape_overlaps sidecar field) but not yet counted for repair.

Evidence: 2026-08-01 factor tree rendered as a labelled root, disconnected line stubs and empty panels; edges + containment + graph layout + shape×shape measurement all shipped that day.
